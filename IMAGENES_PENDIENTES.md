# Imágenes pendientes — Irene Fernández

Las imágenes de stock/provisionales se han eliminado de la web. No hay ninguna URL externa de Unsplash en el proyecto.

Cuando tengamos las fotografías reales, solo hay que colocar los archivos en `public/images/irene/` con estos nombres:

| Slot | Archivo | Uso |
|---|---|---|
| Hero | `irene-hero.webp` | Fotografía principal de portada |
| Retrato | `irene-portrait.webp` | Sobre mí / Contacto |
| Ponencia | `irene-speaking.webp` | Participaciones y eventos |
| Reunión | `irene-meeting.webp` | Experiencia / liderazgo |
| Detalle | `irene-detail.webp` | Visión / piezas editoriales |

Los componentes ya están preparados para sustituir el placeholder automáticamente cuando se añada la imagen.
